# User Story 란?

User Story는 최종 사용자의 관점에서 소프트웨어 기능과 가치를 간단한 문장으로 설명하는 애자일 개발의 핵심 도구

> \[사용자/역할\]로서, \[기능/작업\]을 할 수 있다. 그래서 \[목적/가치\]를 얻을 수 있다.

<br>

# User Story의 주요 특징

-   사용자 중심적 관점에서 작성
-   간단하고 명확한 설명
-   실제 가치와 목적을 포함
-   테스트 가능한 형태로 작성

<br>

# 이커머스의 User Story 예

## 1\. 상품 검색 및 필터링

-   **스토리:** **구매를 원하는 회원**으로서, **가격대별로 상품을 필터링을** 할 수 있다. 그래서 **내 예산에 맞는 상품만 빠르게 골라볼 수 있다.**

## 2\. 소셜 로그인

-   **스토리:** **바쁜 방문자**로서, **카카오톡 계정으로 빠르게 로그인을** 할 수 있다. 그래서 **회원가입 양식을 일일이 입력하는 번거로움을 줄일 수 있다.**

## 3\. 장바구니 상품 편집

-   **스토리:** **쇼핑몰 고객**으로서, **장바구니에 담긴 상품의 수량을 직접 변경**할 수 있다. 그래서 **결제하기 전에 최종 구매 수량을 조절할 수 있다.**
