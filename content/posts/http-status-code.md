# 2xx (성공)

- **200 OK** : 요청이 성공적으로 처리됨. 가장 일반적인 응답 코드.
- **201 Created** : 요청이 성공적으로 이루어져 새로운 리소스가 생성됨. POST 요청을 통해 새로운 엔트리가 데이터베이스에 추가되었을때 주로 사용.
- **204 No Content** : 요청은 성공했지만, 클라이언트에게 보내줄 콘텐츠가 없음. DELETE 요청이 성공적으로 처리되었을때도 사용됨

# 3xx (리다이렉션)

- **301 Moved Permanently** : 요청한 리소스가 영구적으로 새 위치로 이동했음. 이 코드는 리소스의 URL이 변경되었을때 사용됨 
- **302 Found** : 요청한 리소스가 일시적으로 다른 위치에 있음을 나타냄. 리다이렉션을 위해 자주 사용됨.

# 4xx (클라이언트 오류)

- **400 Bad Request** : 서버가 요청을 이해할 수 없음. 잘못된 요청 구조나 파리미터 떄문에 발생할 수 있음.
- **401 Unauthorized** : 요청이 인증을 필요로 함. 보통 로그인하지 않은 사용자가 보호된 리소스에 접근하려 할 때 반환됨
- **403 Forbidden** : 서버가 요청을 이해했으나, 권한이 없어 요청을 거부함.
- **404 Not Found** : 서버가 요청한 리소스를 찾을 수 없음. URL 오류나 존재하지 않는 페이지에 대한 요청에서 흔히 발생함.
- **405 Method Not Allowed** : 요청된 리소스에서는 지원하지 않는 HTTP 메소드를 사용함.
- **422 Unprocessable Entity** : 요청은 이해했으나, 요청된 작업을 수행할 수 없음, 주로 요청 형식이 올바르지만, 요청 내용이 유효하지 않을때 사용됨(예 : 데이터 유효성 검증 실패)

# 5xx (서버 오류)

- **500 Internal Server Error** : 서버 내부 오류로 인해 요청을 처리할 수 없음. 가장 일반적인 서보 오류 응담.
- **503 Service Unavailable** : 서버가 일시적으로 요청을 처리할 수 없음. 일반적으로 서버 과부하나 유지 관리로 인해 발생함.
