# VPC 란?

Virtual Private Cloud로 가상의 네트워크 공간(컴퓨터들끼리 통긴하는 공간)을 의미한다.

VPC를 활용하면 외부에서 직접 접근할 수 없는 독립적인 네트워크 환경을 구성할 수 있어 보안적으로 안전하게 리소스(EC2, RDS 등)를 사용할 수 있다.

예를 들어, EC2 인스턴스 2대가 있을때, 1대의 인스턴스는 인터넷에 자유롭게 접근하면서 사용하고 싶고, 다른 1대는 안전하게 비공개로 사용하고 싶을 수 있따. 이때 VPC를 활용하면 된다.

<br>

# VPC 범위 지정

VPC의 범위를 정할때는 IP 주소의 범위로 정하며, 각 리소스(EC2, RDS, ELB 등)들에 IP 주소를 할당한다.

- ex) 10.10.0.0 ~ 10.10.0.31

VPC의 범위를 지정할떄 IP주소를 CIDR 표기 방식을 사용한다.

<br>

# CIDR 란?

IP 주소의 범위를 나타내기 위한 표기 방법

<br>

> ## CIDR 해석
> 1. 10진수 주소를 모두 2진수로 변환한다.
> 2. CIDR 슬래시 뒤에 있는 숫자를 활용해 앞에서 자른다.
> 3. 잘린 2진수의 왼쪽 값은 그대로 고정하고, 잘린 2진수의 오른쪽 값에서 표현 가능한 최댓값과 최솟값을 구한다.
> 4. 2진수로 표현된 최솟값과 최댓값을 10진수로 변환하면 주소 범위가 나온다.

<br>

## 예시 (13.25.82.0/24)

1\. 10진수를 2진수로 변환한다.

00001101.00011001.01010010.00000000

2\. CIDR 슬래시 뒤에 있는 숫자를 활용해 2진수를 자른다.

00001101.00011001.01010010 / 00000000

3\. 잘린 2진수의 왼쪽 값은 그대로 고정하고, 잘린 2진수의 오른쪽 값에서 표현 가능한 최댓값과 최소값을 구한다.

-   최소값 : 00001101.00011001.01010010 / 00000000
-   최댓값 : 00001101.00011001.01010010 / 11111111

4\. 2진수로 표현된 최솟값과 최댓값을 10진수로 변환한다.

-   최소값 : 13.25.82.0
-   최대값 : 13.25.82.255

5\. 13.25.82.0/24의 주소 범위는 13.25.82.0 ~ 13.25.82.255

<br>

# 공인 IP 란?

공인 IP란 외부 인터넷을 통해 접근할 수 있는 고유한 IP 주소이다. 퍼블릭 IP라고도 한다.

<br>

# 사설 IP 란?

사설 IP란 외부 인터넷과 직접 연결되지 않고, 내부 네트워크에서만 사용되는 주소이다. 프라이빗 IP라고도 한다.

<br>

## 사설 IP의 특징

-   사설 IP는 '동일한 네트워크 환경'에서만 서로 통신할 수 있다. 동일한 네트워크 환경이란 같은 공유기(와이파이)를 사용하거나 같은 VPC인 경우이다.
-   사설 IP는 네트워크 환경마다 중복해서 가질 수 있다.  
    공인 IP는 2개의 컴퓨터가 중복해서 사용할 수 없다. 예를 들어 13.15.262.16 이라는 공인 IP는 전세계에서 딱 1대의 컴퓨터만 사용할 수 있다. 반면 사설 IP는 네트워크 환경마다 독립적으로 사설 IP를 사용할 수 있다. 한 마디로 사설 IP는 각자의 네트워크 환경에서만 사용하는 IP이다. 예를 들어 A라는 네트워크 환경에서 10.0.0.0이라는 사설 IP를 쓰고있다고 하더라도, B라는 네트워크 환경에서도 10.0.0.0을 별개로 사용할 수 있다.

<br>

## 사설 IP 범위

IETF라는 국제 인터넷 표준화 기구에서 사설 IP의 범위를 지정해놓음

| RFC1918 이름 | IP 주소 범위 | 호스트 ID 크기 |
| --- | --- | --- |
| 24비트 블록 | 10.0.0.0 ~ 10.255.255.255 | 24비트 |
| 20비트 블록 | 172.16.0.0 ~ 172.31.255.255 | 20비트 |
| 16비트 블록 | 192.168.0.0 ~ 192.168.255.255 | 16비트 |

사설 IP 범위에 있는 IP 주소로 통신하면 무조건 사설 IP로 인식한다. 즉, 사설 IP 범위에 있는 IP를 공인 IP처럼 사용하지 못한다. 그래서 AWS 인스턴스의 프라이빗 IPv4 주소를 보면 사설 IP 범위의 값이다.

AWS EC2 인스턴스를 생성하고 내 PC에서 EC2의 퍼블릭 IP로는 통신이 가능하지만 프라이빗 IP로 통신에 실패한다. 같은 VPC의 인스턴스를 하나 더 생성하고 두 인스턴스끼리는 프라이빗 IP로 통신이 가능하다.

# AWS VPC 생성

![aws-vpc3](https://www.dropbox.com/scl/fi/e5pfcrbpujwyu7yk187uo/aws-vpc3.png?rlkey=dhkye8h1b77pipulimonfv2wu&st=fibppihl&dl=1)

첫 VPC를 생성할때 주로 10.0.0.0/16 으로 설정을 많이 한다. 10.0.0.0/16은 10.0.0.0 ~ 10.0.255.255의 범위로 65,536개의 IP 범위가 나온다. 10.0.0.0/16은 사설 IP 범위에 포함되며 충분한 IP의 개수를 가지고 있기 때문에 주로 사용된다.
