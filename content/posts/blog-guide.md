# 블로그 글 작성 가이드

이 블로그에서 글을 쓰는 방법과, 마크다운이 화면에 어떻게 보이는지 정리한 문서입니다.

---

## 1. 새 글 만들기

1. `content/posts/` 폴더에 `.md` 파일을 만듭니다.
   - 파일 이름이 주소가 됩니다: `spring-transaction.md` → `/posts/spring-transaction/`
   - 영문 소문자, 숫자, 하이픈(`-`)만 쓰세요. 한글·띄어쓰기는 주소 문제가 생길 수 있습니다.
2. 맨 위에 **front matter**(글 정보)를 씁니다.
3. 그 아래에 본문을 마크다운으로 씁니다.
4. `npm run dev`로 미리 보고, 커밋 후 `git push`하면 1~2분 뒤 배포됩니다.

### front matter

```md
---
title: 스프링 트랜잭션 정리
date: 2026-11-20
category: Spring
description: 목록 카드와 글 상단에 보이는 한두 줄 요약
tags: [spring, transaction]
---
```

| 항목          | 필수 | 설명                                                                |
| ------------- | ---- | ------------------------------------------------------------------- |
| `title`       | ○    | 글 제목                                                             |
| `date`        | ○    | `YYYY-MM-DD` 형식. 시간까지 적으면(`2026-11-17 14:30`) 같은 날짜 글의 순서가 정해집니다. |
| `order`       |      | 날짜·시간이 같을 때 우선순위. 숫자가 클수록 위 (기본 0)            |
| `category`    | ○    | 사이드바 카테고리. 영문 권장 (`Spring`, `Java`, `Database` …)       |
| `description` |      | 목록 카드에 2줄까지 보이는 요약                                     |
| `tags`        |      | `[spring, jpa]`처럼 대괄호와 쉼표. 태그 페이지가 자동으로 생깁니다. |
| `draft: true` |      | 쓰는 중인 글. 목록과 배포에서 빠집니다.                             |
| `thumbnail`   |      | 목록 미리보기 이미지 지정 (`/images/...`), `false`면 미리보기 없음  |

### 같은 날짜 글의 순서 정하기

글 목록(최신 글, 이전·다음 글 포함)은 아래 순서로 정렬됩니다.

1. **날짜·시간이 늦은 글**이 위로. 시간을 적으면 같은 날짜 안에서도 순서가 정해집니다.
2. 날짜·시간이 같으면 **`order` 숫자가 큰 글**이 위로 (안 적으면 0)
3. 그래도 같으면 제목 가나다순

```md
---
title: 오후에 쓴 글
date: 2026-11-17 14:30
---
```

```md
---
title: 맨 위에 두고 싶은 글
date: 2026-11-17
order: 10
---
```

- 목록에는 시간 없이 날짜만 보입니다.
- 시간은 `14:30`처럼 24시간 형식으로 적습니다.

## 2. 제목 (소제목)

```md
## 큰 소제목

### 작은 소제목

#### 더 작은 소제목
```

- 글 제목은 front matter의 `title`이 쓰이므로, 본문에서는 `#`(h1)을 쓰지 말고 **`##`부터** 시작하세요.
- `##`, `###`는 넓은 화면(1440px 이상)에서 오른쪽 **"이 글의 목차"**에 자동으로 나옵니다.
- `##`는 손글씨 네이비 색, `###`는 굵은 글씨로 보입니다.

---

## 3. 문단과 줄바꿈 ⚠️ 가장 많이 헷갈리는 부분

마크다운에서는 **엔터 한 번은 줄바꿈이 아닙니다.** 앞 줄과 이어져 한 문장이 됩니다.

```md
첫 번째 줄
두 번째 줄
```

→ 화면: `첫 번째 줄 두 번째 줄` (한 줄로 이어짐)

| 하고 싶은 것                 | 쓰는 방법                       |
| ---------------------------- | ------------------------------- |
| 문단 나누기                  | 줄 사이에 **빈 줄** 하나        |
| 같은 문단 안에서 줄만 바꾸기 | 줄 끝에 **공백 두 칸** 또는 `\` |

```md
첫 번째 문단입니다.

두 번째 문단입니다.

같은 문단인데 줄만 바꿉니다.\
이렇게요.
```

- 문단 사이 간격은 블로그가 알아서 넣습니다. **`<br>`로 간격을 만들지 마세요.**

## 4. 글자 꾸미기

| 쓰는 방법                          | 결과                                   |
| ---------------------------------- | -------------------------------------- |
| `**굵게**`                         | **굵게**                               |
| `*기울임*`                         | _기울임_                               |
| `~~취소선~~`                       | ~~취소선~~                             |
| `` `인라인 코드` ``                | `인라인 코드` (네이비 글씨, 회색 배경) |
| `[링크 글자](https://example.com)` | 링크 (마우스를 올리면 밑줄이 그려짐)   |

- 클래스·메서드·변수 이름(`EntityManager`, `save()`)은 백틱(`` ` ``)으로 감싸면 읽기 좋습니다.

## 5. 인용문 = 노란 포스트잇 (콜아웃)

`>`로 시작하는 줄은 **노란 포스트잇 상자**로 보입니다. 정의, 핵심 요약, 비유, 주의사항에 쓰세요.

```md
> 영속성 컨텍스트는 "엔티티를 영구 저장하는 환경"이라는 뜻이다.
```

여러 문단·목록도 넣을 수 있습니다. **모든 줄 앞에 `>`**를 붙이고, 문단 사이 빈 줄에도 `>`만 적습니다.

```md
> **흐름 요약**
>
> 1. 개발자가 `save()` 호출
> 2. `EntityManager`가 `persist()` 실행
> 3. 커밋 시점에 SQL 전송
```

- 상자 안의 `**굵게**`는 제목처럼 쓰기 좋습니다.
- ❌ 짧은 용어 하나만 `>`로 감싸지 마세요 (`> **JPA**`). 작은 포스트잇만 덩그러니 생깁니다. 용어 설명은 `###` 소제목을 쓰세요.

## 7. 표

```md
| 문제         | 해결        | 설명                      |
| ------------ | ----------- | ------------------------- |
| 매번 DB 조회 | 1차 캐시    | 한 번 본 건 기억해둡니다. |
| 객체 불일치  | 동일성 보장 | 같은 객체를 돌려줍니다.   |
```

- 첫 줄이 머리글(회색 배경, 네이비 밑줄)이 됩니다.
- 둘째 줄 `| --- |`는 꼭 있어야 합니다.
- 칸 너비를 공백으로 맞출 필요는 없습니다.
- 표가 넓으면 화면 안에서 가로로 스크롤됩니다.

## 8. 코드 블록

````md
```java
public class Hello { }
```
````

### 언어 이름은 꼭 정확하게 ⚠️

첫 줄 ` ``` ` 뒤에 **실제 언어**를 적어야 색이 제대로 입혀집니다.
(Java 코드에 `tsx`를 적으면 대부분 빨간색으로 깨져 보입니다. 언어를 안 적으면 색이 없습니다.)

| 언어          | 이름                                               |
| ------------- | -------------------------------------------------- |
| Java / Kotlin | `java`, `kotlin`                                   |
| SQL           | `sql`                                              |
| 설정 파일     | `yaml`, `properties`, `json`, `xml`, `toml`        |
| Gradle        | `groovy`(build.gradle), `kotlin`(build.gradle.kts) |
| 터미널 명령   | `bash`                                             |
| 웹            | `ts`, `tsx`, `js`, `html`, `css`                   |
| 그 외         | `text` (색 없이)                                   |

### 파일명, 줄 강조, 줄 번호

````md
```java title="OrderService.java" {3-4} showLineNumbers
@Service
public class OrderService {
    @Transactional
    public void order() { }
}
```
````

| 옵션              | 효과                                 |
| ----------------- | ------------------------------------ |
| `title="파일명"`  | 코드 위에 파일명 표시                |
| `{3-4}`           | 3~4번째 줄 강조 (여러 개: `{1,3-5}`) |
| `showLineNumbers` | 줄 번호 표시                         |

- 모든 코드 블록에는 **복사 버튼**이 자동으로 붙습니다.
- 코드 블록을 닫는 ` ``` ` 앞에 빈 줄은 넣지 않아도 됩니다.

## 9. 이미지

### 넣는 방법

1. 이미지를 `public/images/글이름/`에 넣습니다.
   ```
   public/images/persistence-context/structure.png
   ```
2. 본문에 `/images/...` 주소로 적습니다. (`public`은 빼고)
   ```md
   ![영속성 컨텍스트 구조](/images/persistence-context/structure.png)
   ```
3. 따옴표 안 문구를 쓰면 이미지 아래에 **캡션**이 붙습니다.
   ```md
   ![영속성 컨텍스트 구조](/images/persistence-context/structure.png "EntityManager 안에 1차 캐시가 있습니다")
   ```

- `[ ]` 안 글자는 이미지가 안 보일 때와 화면 낭독기에서 읽히는 설명입니다. 비워 두지 마세요.
- 본문의 **첫 이미지**가 글 목록 카드 오른쪽 미리보기가 됩니다.

### 주의

- 파일 이름은 영문·숫자·하이픈으로 (`image 1.png` ❌ → `structure.png` ⭕)
- 사진은 1~2MB 이하로 줄여서 올리세요. PNG보다 JPG/WebP가 가볍습니다.
- `<img src="...">` HTML 태그 대신 `![]()` 문법을 쓰세요.

## 10. 노션에서 복사해 올 때 고칠 것

노션의 "마크다운으로 내보내기"나 복사·붙여넣기 결과는 이 블로그에서 그대로 쓰면 깨지는 부분이 있습니다.

| 노션에서 온 모양               | 문제                                         | 이렇게 바꾸기                                                            |
| ------------------------------ | -------------------------------------------- | ------------------------------------------------------------------------ |
| `<aside> … </aside>` (콜아웃)  | 안의 `` `코드` ``·`**굵게**`가 변환되지 않음 | 각 줄 앞에 `>` 붙이기 (5번 참고)                                         |
| `!image.png`, `![](image.png)` | 이미지 파일이 블로그에 없음                  | 파일을 `public/images/글이름/`에 넣고 `![설명](/images/글이름/파일.png)` |
| `<br>` 여러 개                 | 불필요한 빈 공간                             | 지우기 (간격은 자동)                                                     |
| 엔터 한 번으로 나눈 줄         | 한 줄로 이어짐                               | 빈 줄 넣기 (3번 참고)                                                    |
| 표 머리글의 `**굵게**`         | 머리글이 이미 강조됨                         | `**` 빼기 (그대로 둬도 동작은 함)                                        |
| 코드 블록 언어가 엉뚱함        | 색이 깨짐                                    | 실제 언어로 고치기 (8번 참고)                                            |
